# Bem-vindo ao Basalto

O **Basalto** é um editor de notas Markdown local baseado em cofres, inspirado na arquitetura do Obsidian e reimplementado do zero.

> [!tip] Dica Rápida
> Você pode alternar entre o modo de edição e leitura usando `Ctrl+E` ou a paleta de comandos (`Ctrl+P`).

## Recursos Disponíveis

- [x] Leitura e Live Preview de notas Markdown
- [x] Suporte completo a wikilinks: veja [[Ideias]]
- [x] Fórmulas matemáticas com KaTeX: $E = mc^2$ e $\int_{-\infty}^\infty e^{-x^2} dx = \sqrt{\pi}$
- [x] Diagramas visuais interativos em [[Mapa Mental.canvas]]
- [ ] Criar novas anotações e conectar tags como #basalto e #produtividade

Explore o explorador de arquivos à esquerda ou abra a visualização em grafo com `Ctrl+G`!
